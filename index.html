Descripción del proyecto

Este proyecto tiene como objetivo el crear una aplicaicon web que permita a los usuarios el tener control sobre sus prestamos y deudas, enfocado en los prestamos contando con caracteristicas que permitan el facil uso, interaccion, desplazamiento, y visualizacion de la aplicacion y todos los datos que necesita el usuario

Requisitos técnicos • Usar el CDN de Materialize CSS y JS. • Personalizar al menos 3 componentes de Materialize (navbar, cards, buttons, forms, modals, etc.). • Crear una hoja de estilos personalizada (style.css) para ajustar colores, márgenes o tipografías. • Añadir al menos una pequeña función JavaScript, como: o Validar el formulario. o Cambiar el color de fondo al hacer clic. o Mostrar un mensaje de bienvenida con alert() o toast.
