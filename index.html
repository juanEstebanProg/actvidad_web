Descripción del proyecto

Este proyecto tiene como objetivo crear una aplicación web que permita a los usuarios tener control sobre sus préstamos y deudas, enfocada en los préstamos, con características que faciliten el uso, la interacción, el desplazamiento y la visualización de la aplicación y de todos los datos que necesita el usuario.
