Proyecto Integrador I

Conoce a nuestro equipo

Trabajamos en una herramienta sencilla para organizar préstamos y deudas.

Nuestro propósito

Una mejor forma de llevar las cuentas

flag Misión

Desarrollar una aplicación web clara y fácil de usar que ayude a las personas a registrar y consultar sus préstamos y deudas, para que puedan llevar un mejor control de sus compromisos financieros.

visibility Visión

Ser una herramienta práctica y confiable para organizar las cuentas personales, facilitando el seguimiento de cada préstamo desde una experiencia accesible y ordenada.
